# Hudson Travel frontend

This Vue 3 and Vite interface searches the Hudson Travel FastAPI backend by
hotel name and displays the matching fixed-date stays. See the repository `README.md`
for setup and `docs/verification.md` for the complete Part 1 checks.

From this directory:

```bash
npm install
npm run dev
```

Available checks are `npm test`, `npm run lint`, and `npm run build`.
